# JP Study Notes

**Структуровані нотатки з вивчення японської мови українською.**

Цей проєкт створений, щоб зробити якісні матеріали з японської мови доступними для українськомовної спільноти.

---

## Мета проєкту

- Створити повний конспект від N5 до N1
- Покрити не лише побутову, а й бізнес та ІТ лексику
- Зробити матеріали зручними для самостійного навчання

---

## Розділи

| Розділ | Опис |
|--------|------|
| **N5** | Початковий рівень: абетки, базова граматика, ~800 слів |
| **N4** | Елементарний рівень: складніші конструкції, ~1500 слів |
| **Бізнес та ІТ** | Спеціалізована лексика, кейго, технічні терміни |
| **Ресурси** | Корисні посилання, словники, Anki колоди |
